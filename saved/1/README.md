# Academy website assets

The website is deployed at https://anusha-art-academy.onrender.com/.

Run the Flask app from the repository root for a complete preview; see the root README. Registration uses the same-origin `/api/registrations` endpoint and one styled form. It saves to the existing academy Google Form only after validation and confirmed receipt. Google Sheet response linking requires owner access. Do not run a plain static server to test submissions.

`academy-content.js` contains public content settings. Events use the public Google Doc; new album Slides appear first. Video URLs are pending.

Academy photographs and artwork are client-supplied; no reuse license is granted.
