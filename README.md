# Anusha Art Academy

Final Demo 1 website for Anusha Art Academy, Kondapur. Static HTML, CSS and JavaScript with the academy album, class timetable, interactive course details and upcoming-events scroll.

## Local preview

Run `python3 -m http.server 4187` from this folder, then open http://127.0.0.1:4187/.

## Content

`academy-content.js` contains contact/review settings, teacher profiles and upcoming-event configuration. `experience.js` manages the album and video placeholders.

Registration remains a local preview until `registrationEndpoint` is connected. Upcoming events are blank until content or `workshopsEndpoint` is configured. Video sources and additional teacher details are pending.

This repository does not configure hosting, GitHub Pages or deployment workflows. Academy photographs and artwork are client-supplied; no reuse license is granted.
